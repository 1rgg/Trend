# 2026-08-27 工作日志

## Trend 项目改造：静态数据 → 纯前端实时行情

用户希望实现"实时查看走势 + 自行搜索任意基金/股票/指数"。原项目是 GitHub Pages 纯静态，数据靠 AkShare 预抓 JSON（T+1，固定 9 个资产池，下拉选择）。

**决策**：采用方案 A —— 前端直连东方财富公开 JSONP 接口，保持纯静态部署，去掉所有静态数据。AkShare 底层也是抓东财，等价实现。

**改动**：
- `js/app.js` 重写：JSONP 工具 + 东财接口封装（搜索/kline/分时/pingzhongdata净值）+ 搜索建议 + 分时/K线(candlestick)/净值曲线渲染 + 盘中自动刷新
- `index.html`：搜索框+建议下拉替代固定select，加周期(分时/日周月K)、复权、区间、自动刷新、市场状态
- `css/style.css`：补搜索建议、复权chips、自动刷新行、警告样式
- 删除 `data/`、`scripts/fetch_data.py`、`requirements.txt`
- 重写 `README.md`

**关键技术点（踩坑记录）**：
1. 东财搜索接口 `searchapi.eastmoney.com/api/suggest/get` 返回结构是 `QuotationCodeTable.Data`（非 QuotationData），每条带 `QuoteID`（如 `1.600519`）可直接当 secid，`Classify` 判类型：`OTCFUND`=场外基金(走净值)、`Fund`=ETF(走K线)、`AStock`=个股、`Index`=指数。`MktNum` 是 `"1"/"2"`（非旧文档的14/15）。
2. 中文搜索：curl 命令行不编码会 400，浏览器 `encodeURIComponent` 正常。
3. 分时接口 trends2 返回 7 列（4个价格+vol+amount），需用倒数取 vol/amount 兼容 5/7 列。
4. `fundgz.1234567.com.cn` 实时估值接口已下线（404），`fundmobapi` 不支持 JSONP → 场外基金实时估值降级，改用 pingzhongdata.js 的 `Data_netWorthTrend` 净值历史 + 当日涨跌。
5. kline/trends/搜索 都支持 `cb` 参数做 JSONP；pingzhongdata 是全局变量注入式脚本，需 loadScriptOnce + 读 window 全局变量。

**验证**：curl 验证全部接口格式正确；node --check 语法 OK；本地 http.server 起服务 HTTP 200。

## 故障修复：东财 push2his 反爬导致搜索/K线全部失效

**现象**：页面搜索选完标的后图表加载失败（JSONP 空响应），周期/复权/区间点击体感"没反应"。浏览器实测控制台报 `net::ERR_EMPTY_RESPONSE` / curl exit 52/56。

**根因**：东方财富 push2his 系列 K线接口 2026 年起加强反爬，无登录 Cookie（`ct=`）一律返回空响应（参考 efinance#235）。searchapi.eastmoney.com 搜索接口仍可用但偶发限流空响应。

**修复**（js/app.js 数据层重写 + index.html 文案）：
1. K线/分时切腾讯财经 `web.ifzq.gtimg.cn`：
   - K线 `/appstock/app/fqkline/get?param={symbol},{day|week|month},,,{count},{qfq|hfq|}&_var=__x`，返回键名带复权前缀（qfqday/hfqday/day），行为 [date,open,close,high,low,volume]
   - 分时 `/appstock/app/minute/query?code={symbol}&_var=__minute`，点串 "HHMM 价 累计量 累计额"，均价=累计额/累计量、成交量需差分，昨收在 qt[code][4]
   - 均为「变量注入式」脚本接口（无回调 JSONP），新增 fetchVar() 工具；**漏加 `_var` 参数会被 ORB 拦截**（JSON 非 JS）
2. 搜索双源：东财 searchapi（支持拼音缩写如 nndx）+ 重试一次，失败降级腾讯 smartbox `s3/?v=2&q=&t=all`（仅全拼/中文/代码，GBK 编码需 script.charset='gbk'，类型码 F* 视作场外基金）
3. 基金净值 pingzhongdata 必须用 https（http 会 301）
4. index.html 引 app.js 加 ?v= 版本参数防缓存

**端到端验证**：browser_use 实测 分时/日周K/三种复权/区间切换/搜索切股 全部通过（茅台 metric 从 3935→1291.16）。注意：自动化 browser_click 对该下拉项派发不可靠，programmatic li.click() 才验通，属工具限制非页面 bug。腾讯 smartbox 不支持 nndx 这类首字母缩写，此能力依赖东财搜索可用性。
